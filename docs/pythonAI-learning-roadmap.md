# 完全免費且可直接開始的 Python 學習路線（已有程式基礎）

## 建議學習路線（Free + Start Now）

1. **Google’s Python Class**（先快速校準 Python 語法手感）  
   https://developers.google.com/edu/python/  
   - 目標：用最短時間補齊 Python 常用語法與標準操作（字串、list、檔案、HTTP）
   - 建議時間：1–3 天

2. **Harvard CS50P**（系統化打底、養成寫程式習慣）  
   https://pll.harvard.edu/course/cs50s-introduction-programming-python  
   - 目標：把 Python fundamentals 變成可穩定輸出的能力（函式/OOP/測試等）
   - 建議時間：2–4 週（可自行加速）

3. **MIT 6.0001 (OCW)**（強化 CS 思維與問題拆解）  
   https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/  
   - 目標：演算法思維、遞迴、嚴謹的 problem-solving
   - 建議時間：2–5 週

4. **Microsoft Python for Beginners**（補齊工程化細節）  
   https://learn.microsoft.com/training/paths/beginner-python/  
   - 目標：套件管理、測試、API 實作，銜接實務開發
   - 建議時間：1–2 週

5. **IBM Python for Data Science, AI & Development**（轉向資料/AI 應用）  
   https://www.coursera.org/learn/python-for-applied-data-science-ai  
   - 目標：Pandas、NumPy 與資料導向 Python 應用
   - 建議時間：1–3 週（旁聽免費）

## 為什麼這樣排（已有程式基礎版）

- **Google**：最短路徑進入 Python
- **Harvard**：把語法變成穩定能力
- **MIT**：拉高抽象與解題層次
- **Microsoft**：把程式寫成可維護、可整合
- **IBM**：再往 Data/AI 場景延伸

## 免費條件說明

- 上述內容都可免費取得學習內容。
- **Coursera（IBM）證書通常需付費**，但可旁聽免費內容。
- Harvard / MIT 若要官方認證證書，可能有付費選項；純學習可免費進行。
