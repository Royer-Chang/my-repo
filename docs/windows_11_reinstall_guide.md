# Windows 11 UEFI 開機與系統重灌完整指南

本指南整合了從硬碟開機區建立、Rufus 圖像化工具操作、BIOS 關鍵設定調整，到 Windows 11 實際安裝步驟的完整流程。

---

## 📋 核心流程總覽

1. **製作開機碟**：使用 **Rufus** 自動化工具，將 Windows 11 ISO 寫入隨身碟（設定為 **GPT / UEFI**）。
2. **調整 BIOS**：開啟 **UEFI**、**TPM 2.0** 與 **Secure Boot**，以符合 Win11 硬體規範。
3. **引導開機**：透過主機板 **Boot Menu** 快捷鍵選擇隨身碟開機。
4. **系統安裝**：清除舊系統磁碟區，由 Windows 自動建立符合 UEFI 規範的磁區並完成安裝。

---

## 一、 使用 Rufus 自動化製作開機隨身碟

### 🛠 事前準備
1. **USB 隨身碟**：容量至少 **8 GB** 以上（製程中會抹除所有資料）。
2. **Windows 11 ISO 檔**：至微軟官網下載官方映像檔。
3. **Rufus 軟體**：至 Rufus 官網下載最新版本（建議 Portable 免安裝版）。

### ⚡ Rufus 設定步驟
1. **插入隨身碟**並開啟 `rufus.exe`。
2. **裝置 (Device)**：確認選取目標隨身碟。
3. **開機型式 (Boot selection)**：點選右側「**選擇 (SELECT)**」，載入 Windows 11 ISO 檔。
4. **資料夾架構 (Partition scheme)**：務必切換為 **GPT**。
5. **目標系統 (Target system)**：系統會自動鎖定為 **UEFI (非 CSM)**。
6. **檔案系統 (File system)**：保持預設（通常為 FAT32 或由 Rufus 自動優化）。
7. **執行 (START)**：
   * 隨後會跳出 Windows User Experience 視窗，可自由勾選是否繞過 TPM 2.0 / Secure Boot / 微軟帳號限制。
   * 點選確定，並同意資料抹除警告，等待進度條跑滿顯示「**準備就緒 (READY)**」即可關閉。

## 二、 重灌前的 BIOS 設定調整

開機畫面亮起時，連續按下 `Del` 或 `F2` 進入 BIOS（依主機板而定），請務必修改或確認以下三項設定：

| 設定項目 | 作用與說明 | 建議設定值 |
| :--- | :--- | :--- |
| **CSM (相容性支援模組)** | 關閉舊版相容模式，強制純 UEFI 開機 | **Disabled (關閉)** / **UEFI Only** |
| **TPM 2.0 (信賴平台模組)** | Windows 11 強制要求的安全性硬體檢查 | **Enabled (開啟)** <br>*(Intel 稱 **PTT** / AMD 稱 **fTPM**)* |
| **Secure Boot (安全開機)** | 確保開機載入的作業系統安全無虞 | **Enabled (開啟)** <br>*(模式設為 **Standard**)* |

> 💡 **儲存並離開**：設定完成後，按下 **`F10`** 儲存變更並自動重啟電腦。

---

## 三、 使用隨身碟引導開機

1. 電腦重啟畫面剛亮起時，連續按下主機板的 **Boot Menu（開機選單）快捷鍵**：
   * **ASUS**: `F8`
   * **Gigabyte**: `F12`
   * **MSI**: `F11`
   * **Lenovo / Acer**: `F12`
   * **HP**: `F9`
2. 在彈出的選單中，選取名稱帶有 **`UEFI: [你的隨身碟名稱]`** 的選項，按下 Enter 進入 Windows 安裝界面。

## 四、 Windows 11 安裝與硬碟分割操作

### 流程步驟
```
[語系設定] 選擇台灣、繁體中文 → 點選「立即安裝」
      ↓
[輸入產品金鑰] 輸入序號，或點選「我沒有產品金鑰」(安裝完再授權)
      ↓
[選擇版本] 選擇你原本擁有的版本（如：Windows 11 家用版/專業版）
      ↓
[安裝類型] 務必點選「自訂：唯獨安裝 Windows (進階)」
      ↓
[硬碟分割] (重灌核心步驟，請見下方詳細說明)
      ↓
[自動安裝] 系統開始複製檔案，期間會自動重啟數次（重啟時可拔掉隨身碟）
      ↓
[OOBE 設定] 進入全新開機引導，依序設定地區、鍵盤配置、登入微軟帳號，即可進入桌面
```

### 磁碟分割黃金法則（自訂安裝界面）
* **重灌目標磁碟**：在清單中找到舊的系統碟，將其對應的 C 槽，以及周邊的小磁區（如：系統保留、MSR、恢復、主要等分割區）**一一點選並點擊「刪除」**。
* **合併未分配空間**：刪除後，這些磁區會合併為一整塊「**磁碟 X 的未分配空間**」。
* **直接下一步**：直接選取該未分配空間並點擊「**下一步**」，Windows 11 會自動為新系統切好符合 UEFI 規範的 GPT 磁區並開始安裝。

> ⚠️ **安全警告**：請務必根據容量大小認清硬碟，**切勿刪除**儲存重要資料的非系統碟（如 D 槽或 E 槽），以免造成資料遺失。
