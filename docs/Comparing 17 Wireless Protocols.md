# IoT 無線通訊技術比較：資料速率 vs 覆蓋距離

這張圖比較了常見的無線通訊技術，重點在於觀察兩個維度：

- 資料速率（Data Rate）：越往上，代表速度越快
- 覆蓋距離（Range）：越往右，代表傳輸距離越遠

整體而言，無線技術通常存在一個取捨關係：

- 傳輸距離越遠，通常資料速率越低
- 資料速率越高，通常覆蓋距離越短
- 不同技術是依照不同需求設計，而不是單純比較「哪個更好」

## 技術逐項說明

### RFID
RFID 位於圖的左下角，代表它的傳輸距離極短，資料速率也很低。這類技術最適合做「辨識」而不是大量資料傳輸，例如：

- 門禁卡
- 資產追蹤
- 商品標籤
- 倉儲盤點

### BLE / Zigbee / Z-Wave
這三類技術集中在短距離的低功耗區域，適合低資料量、長時間運作的設備，例如：

- BLE：穿戴裝置、Beacon、手機連線
- Zigbee：智慧照明、感測器網路
- Z-Wave：家居自動化、智慧門鎖

這些技術的優點是「省電」與「適合長時間使用」，但資料速率通常不高。

### Bluetooth
Bluetooth 位於 BLE 之上的區域，意味它的速度略高，適合需要一定資料傳輸量的設備，例如：

- 耳機
- 鍵盤
- 滑鼠
- 裝置配對

它比 BLE 更適合高頻傳輸，但一般功耗略高。

### Wi‑Fi
Wi‑Fi 位於圖中中上區域，表示它具有相對高的資料速率，適合：

- 個人與企業網路
- 影片串流
- 檔案傳輸
- 智慧裝置連線

不過 Wi‑Fi 的功耗通常較高，不適合長時間電池供電的低功耗 IoT 裝置。

### Wi‑Fi HaLow
Wi‑Fi HaLow 比傳統 Wi‑Fi 有更長的傳輸距離，並維持較低功耗，因此特別適合：

- 工業感測
- 智慧農業
- 遠端監控
- 長距離室內/室外連線

它是典型 Wi‑Fi 與低功耗 IoT 之間的折衷方案。

### Licensed LPWAN
這一類技術包括：

- LTE-M
- EC-GSM
- NB-IoT

它們位於圖中中下方，代表長距離、低功耗、低資料量的特性。適合：

- 智慧電表
- 遠端感測
- 城市基礎設施監控
- 需要大範圍覆蓋的 IoT

這類技術通常由電信網路承載，穩定性高，安全性較好。

### Unlicensed LPWAN
這一類技術包含：

- LoRa
- Sigfox
- MIOTY

其特點是：

- 超長距離
- 低功耗
- 零散部署成本低
- 適合偏遠地區或大規模感測器網路

常見於：

- 農業監測
- 環境資料收集
- 偏遠地區設備監控
- 工業與基礎設施感測

### Cellular（3G/4G/5G）
Cellular 技術位於圖中最右側且較高的位置，代表它同時具備：

- 長距離覆蓋
- 高資料速率
- 頗強的行動網路支援

常見於：

- 手機網路
- 行動熱點
- 車聯網
- 影音傳輸
- 工業 4.0 及智慧城市

其中 5G 具備更高吞吐量與更低延遲，適合複雜、高資料量的場景。

## IoT 情境選型建議

| 應用情境 | 建議技術 | 原因 |
|---|---|---|
| 很短距離識別與追蹤 | RFID | 成本低、簡單、適合辨識 |
| 穿戴裝置、健康與行動裝置 | BLE | 低功耗、支援普遍 |
| 智慧家居與自動化控制 | Zigbee / Z-Wave / BLE | 適合低功耗、短距離設備 |
| 高速本地傳輸 | Wi‑Fi | 速度快、泛用性強 |
| 長距離低功耗傳輸 | LoRa / NB-IoT / LTE-M | 適合電池供電設備 |
| 偏遠地區感測 | LoRa / Sigfox / MIOTY | 超長距離、低功耗 |
| 大規模城市感測 | NB-IoT / LTE-M | WAN 覆蓋能力強 |
| 需要即時影音或高頻資料 | 4G / 5G / Wi‑Fi | 高速與較低延遲 |
| 需要大量設備連線 | LPWAN / NB-IoT | 支援大規模覆蓋 |

## 簡單選型原則

### 1. 先看距離
- 極短距離：RFID
- 短距離：BLE / Zigbee / Z-Wave / Bluetooth
- 中距離：Wi‑Fi
- 長距離：LPWAN / Cellular

### 2. 再看資料量
- 大資料量：Wi‑Fi / 4G / 5G
- 小資料量：BLE / Zigbee / LoRa / NB-IoT / RFID

### 3. 再看功耗
- 低功耗：BLE / Zigbee / LoRa / NB-IoT
- 高功耗接受度：Wi‑Fi / 4G / 5G

---

## 結論

這張圖的核心是要說明：

- 無線通信技術沒有「最強」的單一選擇
- 要依照實際需求選擇合適的通訊方式
- 速率、距離與功耗是三個主要 trade-off

簡單來說：

- 想要高速：選 Wi‑Fi / 4G / 5G
- 想要長距離低功耗：選 LoRa / NB-IoT / LTE-M
- 想要短距離低耗電：選 BLE / Zigbee / Z-Wave
- 想要識別/標籤：選 RFID
