# DigiKey Hackathon 參賽專案參考資料整理

## 1. 欲解決問題與構想動機

### 問題描述
在現代家庭中，空氣品質、舒適度與能源消耗已成為高頻且長期存在的生活問題。許多家庭仍缺乏一個整合式的智慧中控工具，導致以下痛點：
- 室內空氣品質難以即時感知，如 PM2.5、CO2、VOC 等數值變化不易被使用者察覺
- 溫濕度異常會影響舒適度與健康，例如過熱、過濕、通風不足
- 電器使用方式缺乏可視化與提醒，容易造成能源浪費
- 傳統設備多為單一功能，缺乏統一的平台能同時做感測、判斷、提醒與控制

### 構想動機
我們希望透過 M5Stack 主機建立一個具體且可展示的智慧家庭產品，將環境感測、健康判斷與節能管理整合在同一個平台上。  
此作品的核心目標不是僅做感測器，而是建立一個有產品感、可操作、可展示的家庭中控裝置，讓使用者能在一個 UI 中理解：
- 家中現況如何
- 是否存在健康風險
- 是否有節能優化機會
- 是否要立即開啟風扇、燈光或其他設備

## 2. 解決方案設計構想

### 作品名稱
M5Stack 智慧家庭健康與能源管理中心  
HomeSense Hub

### 設計概念
本作品以 M5Stack CoreS3 Thread BR 為核心主機，整合以下感測模組與控制模組：
- 溫濕度感測：ENV III
- PM2.5 感測：PMSA003I
- CO2 感測：MH-Z19B（可選）
- VOC / eCO2 感測：SGP30（可選）
- 光照感測：BH1750（可選）
- 控制元件：Relay / 風扇 / 燈光 / 插座
- 告警元件：Buzzer / LED

### 核心方案
1. 環境感測
   - 即時監控室內溫度、濕度、PM2.5、CO2、VOC 與光照
   - 透過感測器即時更新家庭環境狀態

2. 健康與舒適度判斷
   - 根據數據計算舒適度分數
   - 若濕度過高、PM2.5 偏高、CO2 偏高，給出提醒與建議

3. 節能管理
   - 判斷是否長時間開燈、長時間風扇運轉或設備持續高耗能
   - 提供節能建議，協助使用者降低能源浪費

4. 智慧設備控制
   - 透過 M5Stack 觸控 UI 直接控制燈光、風扇或插座
   - 可擴張到更多 IoT 家電設備

5. 告警系統
   - 異常狀態會觸發 LED / Buzzer / UI 提示
   - 使使用者能快速知道需要處理的問題

### 產品價值
這個方案不只是感測器展示，而是一個具備：
- 視覺化 UI
- 健康評估邏輯
- 節能建議
- 設備控制
- 異常警報

的完整產品型解決方案。  
這更符合 DigiKey Hackathon「完整產品體驗」的評審期待。

## 3. 技術可行性評估

### 技術可行性
本方案的技術可行性高，理由如下：
- M5Stack 是適合做原型與展示型產品的平台
- ESP32 系列具備 Wi-Fi、低功耗、簡單串接感測器能力
- M5Stack 具有內建顯示器與觸控能力，便於製作 HMI
- 可用 Arduino / PlatformIO 開發，開發門檻相對合理
- 感測器模組成熟，適合單人開發

### 主要技術模組
- 主控：M5Stack CoreS3 Thread BR
- 感測：ENV III、PMSA003I、MH-Z19B、SGP30、BH1750
- 通訊：Wi-Fi / MQTT（可選）
- 控制：Relay、Buzzer、LED
- UI：M5Stack 顯示器與觸控界面

### 開發可行性
- 1 人參賽可行
- 區分優先順序後，先完成最小可展示版本即可
- 可先做「最核心的 demo 功能」
  - 溫濕度顯示
  - PM2.5 / CO2 / VOC 判定
  - 安全 / 節能警報
  - M5Stack 觸控控制設備
- 這樣版本的成品可在短時間內做出並穩定展示

### 開發策略
建議採用分層架構：
- 感測層：讀取數值
- 邏輯層：計算舒適度與風險
- 控制層：Relay / 警報控制
- UI 層：M5Stack 介面
- 通訊層：MQTT / Wi-Fi（可選加分）

這樣的設計使得專案可逐步擴張，不會因為一開始功能過多而造成開發卡住。

## 4. 商業化或社會影響評估

### 商業化潛力
此作品具有清晰的市場價值，因為家庭健康與節能管理為高頻需求：
- 教育場域：校園、教室環境監測
- 環境場域：室內空氣品質管理
- 醫療保健場域：高風險人群、長照環境監測
- 智慧家庭場域：智慧中控、節能提醒、設備控制

### 社會影響
作品不只是提升家庭便利性，更能帶來以下社會效益：
- 讓使用者更容易了解室內環境健康狀況
- 提升家中舒適度與居家安全
- 降低長時間不必要的能源浪費
- 促進對 IoT、智慧家庭與環境感測的普及理解

### 競賽價值
從競賽觀點，此作品有以下優點：
- 產品體驗完整，不只是感測器
- 能展示 firmware、UI、感測、控制邏輯整合
- 易於評審理解與演示
- 有清楚的落地價值與未來擴展潛力
