# Claude / ChatGPT / Copilot 通用 Prompt 最終版

> 這份清單採用三平台通用格式，可直接複製貼上使用。  
> 使用方式：把 `[方括號]` 內容替換成你的實際需求。

---

## 統一格式（建議所有任務都用這個骨架）

```text
[模式] /[command]

[角色]
你是 [角色描述]。

[任務]
請完成：[任務目標]。

[輸入]
[貼上背景、資料、限制條件]

[輸出格式]
[指定格式：條列 / 表格 / JSON / 程式碼 / 三行摘要]

[約束]
- 聚焦於：[範圍]
- 避免：[不需要的內容]
- 若資訊不足，先列出缺口再給最佳可行方案
```

## 16 個通用 Prompt 清單（可直接貼上）

## 1) /godmode（全力專家模式）

```text
[模式] /godmode

[角色]
你是資深 [領域] 專家與策略顧問。

[任務]
請處理「[任務]」，先做完整分析，再提出可執行方案。

[輸入]
[背景資訊]

[輸出格式]
1. 目標與成功標準
2. 關鍵限制與風險
3. 推薦方案（含理由）
4. 分步執行計畫
5. 備用方案

[約束]
- 明確列出 trade-off
- 以可落地執行為優先
```

---

## 三平台貼上注意事項（Claude / ChatGPT / Copilot）

- **Claude**：保留 `[模式] /command` 行可幫助你快速切換任務風格。  
- **ChatGPT**：若回應過長，可加一句「先給精簡版，再給完整版」。  
- **Copilot**：若用在程式任務，建議在 `[輸入]` 補上「語言/框架/檔案路徑/限制」。
