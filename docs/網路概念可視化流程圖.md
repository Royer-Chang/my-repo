# 網路概念可視化流程圖（可匯出）

## 1) 網頁請求全流程（從輸入網址到資料庫）

```mermaid
flowchart LR
    U[👤 使用者 User] --> B[🌐 Browser 瀏覽器]
    B --> DNS[🧭 DNS 查詢網域]
    DNS --> IP[🔢 取得伺服器 IP]
    IP --> TCP[🤝 TCP 三向交握]
    TCP --> TLS[🔐 TLS 握手 / HTTPS 加密]
    TLS --> FW[🛡️ Firewall 防火牆]
    FW --> RP[🚦 Reverse Proxy 反向代理 Nginx]
    RP --> LB[⚖️ Load Balancer 負載平衡]
    LB --> APP1[🖥️ App Server A]
    LB --> APP2[🖥️ App Server B]
    APP1 --> DB[(🗄️ Database)]
    APP2 --> DB
    DB --> APP1
    DB --> APP2
    APP1 --> B
    APP2 --> B
    B --> U
```

## 2) OSI 7 層對照（由上到下）

```mermaid
flowchart TB
    L7[7️⃣ Application 應用層<br/>HTTP / WebSocket / DNS]
    L6[6️⃣ Presentation 表示層<br/>TLS/SSL, 編碼, 壓縮]
    L5[5️⃣ Session 會話層<br/>連線管理]
    L4[4️⃣ Transport 傳輸層<br/>TCP / UDP, Port]
    L3[3️⃣ Network 網路層<br/>IP / Routing]
    L2[2️⃣ Data Link 資料鏈結層<br/>MAC / ARP]
    L1[1️⃣ Physical 實體層<br/>網線, Wi-Fi 訊號]

    L7 --> L6 --> L5 --> L4 --> L3 --> L2 --> L1
```

## 3) 家用網路：Private IP 經 NAT 上網

```mermaid
flowchart LR
```

## 4) TCP vs UDP（可靠性 vs 速度）

```mermaid
flowchart TB
    subgraph TCP[🤝 TCP：可靠傳輸]
      T1[送出封包 1] --> T2[ACK 確認]
      T2 --> T3[封包遺失? 重傳]
      T3 --> T4[按順序重組]
    end

    subgraph UDP[⚡ UDP：快速傳輸]
      U1[直接送出資料] --> U2[不等待 ACK]
      U2 --> U3[可能遺失/亂序]
      U3 --> U4[低延遲]
    end
```

```mermaid
sequenceDiagram
```
